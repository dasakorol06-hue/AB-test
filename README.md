Данный проект посвящен исследованию поведения пользователей мобильного приложения с использованием методов A/B-тестирования. В рамках работы были проанализированы логи действий пользователей, проведена сегментация аудитории по ключевым метрикам и проверена статистическая значимость различий между контрольной и тестовой группами.

### Цели исследования
- Проанализировать поведение пользователей в мобильном приложении
- Сегментировать аудиторию по ключевым метрикам: удержание, конверсия, средний чек
- Провести A/B-тест для оценки эффективности нового онбординга
- Сформулировать рекомендации для продуктовой команды

## Датасет

В проекте используется датасет **"Light Theme and Dark Theme: Case Study"** с Kaggle.

**Описание данных:**
- **Количество записей:** ~1000 пользователей
- **Основные поля:**
  - `Theme`: группа (Light Theme / Dark Theme)
  - `Conversion Rate`: конверсия в целевое действие (0-1)
  - `Click Through Rate`: кликабельность (0-1)
  - `Bounce Rate`: показатель отказов (0-1)
  - `Session_Duration`: длительность сессии (сек)
  - `Scroll_Depth`: глубина прокрутки (%)
  - `Age`: возраст пользователя
  - `Location`: геолокация

## Методология

### 1. Сегментация аудитории
Пользователи были сегментированы по следующим критериям:
- **Возрастные группы** (<25, 25-34, 35-49, 50+)
- **Поведенческие паттерны** (время сессии, глубина прокрутки)
- **Демографические характеристики** (локация)

### 2. Статистические методы
Для проверки гипотез использовались два подхода:

| Метод | Описание | Применение |
|-------|----------|------------|
| **t-критерий Стьюдента** | Параметрический тест для сравнения средних | Для справки (данные не нормальны) |
| **Bootstrap** | Непараметрический метод ресемплинга | Основной метод (устойчив к ненормальности) |

### 3. Метрики оценки
- **Primary Metric:** Conversion Rate (конверсия в целевое действие)
- **Secondary Metrics:** Click Through Rate, Bounce Rate, Session Duration
